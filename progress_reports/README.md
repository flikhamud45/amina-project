# Progress reports

One Markdown file per work session or milestone, named `YYYY-MM-DD_<topic>.md`, newest last.
Each report says what was asked, what was done, what came out (with numbers and file paths), what
went wrong and how it was handled, and what is still open. Reports are written for teammates who
were not there. They are a record, and are not edited later except to fix errors.
