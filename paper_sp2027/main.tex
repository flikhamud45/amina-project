\title{Sampling Is Not Enough:\\ Fast and Sound Proofs of Inference\ifdefined\pviextended\\ (Extended Version)\fi}

\author{\IEEEauthorblockN{Anonymous Authors}
\IEEEauthorblockA{Submission under double-blind review}}

\maketitle

\begin{abstract}
A client that queries an open-weight model served by someone else cannot tell whether the provider ran the agreed model. Proofs of inference address this in two ways. Proofs built on zkSNARKs are sound but take minutes per query on a large model. Lighter protocols check only a random sample of the computation, which makes them fast; the path protocol of Anchuri et al., for example, is proven sound against a provider that runs a different model. This restriction matters: a provider that changes a single neuron and recomputes the rest of the network honestly leaves one inconsistent value, which a random path almost never inspects; on OPT-6.7B, such an edit changes the next token for \AttackOptLSucceeded{} of \AttackOptLPrompts{} prompts. The problem is not specific to that protocol: we prove that, on some network, every verifier that samples a commitment with local openings accepts a forgery unless it reads most of a layer. In this paper we present a verifier that rejects every wrong answer, not only a different model's, without a SNARK. It checks random linear combinations of every layer, needs only a hash function, and accepts a wrong output with negligible probability. The client needs neither a GPU nor the weights, only their 32-byte Merkle roots or a small key derived from them. Our prover is over 200$\times$ faster than zkLLM's on the same GPU and faster than every other fully sound system we compare with; the only ones that verify faster take minutes to prove each query. The cost is proof size, which a variant reduces about 2$\times$.
\end{abstract}
