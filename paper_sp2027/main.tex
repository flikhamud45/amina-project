\title{Certified but Compromised: Breaking and Fixing\\ Lightweight Proofs of Inference\ifdefined\pviextended\\ (Extended Version)\fi}

\author{\IEEEauthorblockN{Anonymous Authors}
\IEEEauthorblockA{Submission under double-blind review}}

\maketitle

\begin{abstract}
A client that queries an open-weight model served by someone else cannot tell whether the provider ran the agreed model. Proofs of inference address this, but so far they force a choice. Earlier proofs built on zkSNARKs are sound but take minutes per query on a large model. Lighter protocols check only a random sample of the computation, which makes them fast; the path protocol of Anchuri et al., for example, is proven sound against a provider that runs a different model. We show that this restriction matters. A provider that changes a single neuron and recomputes the rest of the network honestly leaves one inconsistent value, which a random path almost never inspects; on a real large language model, such an edit changes the answer. The problem is not specific to that protocol: we prove that every verifier that samples a commitment with local openings can be fooled on some network, whereas a commitment based on a linear code, each of whose queries depends on all the weights, is not. This is enough to obtain full soundness without a SNARK. Our verifier checks every matrix product of an exact int8 model against a linear-code commitment to the weights, using only a hash function, and a wrong output passes with negligible probability. The client needs neither a GPU nor the weights, only a small key derived from them. The prover is orders of magnitude faster than the zkSNARK provers we compare with, including zkLLM's on the same GPU, and faster than every other fully sound system we compare with; the only systems that verify faster take minutes to prove each query. The cost is a proof that grows with the input, which a variant of the protocol reduces.
\end{abstract}
