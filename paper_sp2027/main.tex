\title{Certified but Compromised: Breaking and Fixing\\ Lightweight Proofs of Inference\ifdefined\pviextended\\ (Extended Version)\fi}

\author{\IEEEauthorblockN{Anonymous Authors}
\IEEEauthorblockA{Submission under double-blind review}}

\maketitle

\begin{abstract}
Lightweight proofs of inference check a sample of a committed execution trace. This is not fully sound. A provider that overwrites one neuron and recomputes the later layers honestly leaves one inconsistent site, which the path protocol of Anchuri et al.\ misses with probability $1-1/N$ per path in a layer of width $N$; on OPT-6.7B, one edited neuron changed the next token for 40 of 40 prompts. We prove that every verifier making $q$ queries per layer to a weight commitment of locality $d$, even an adaptive one reading the whole trace, accepts such a forgery on some network with probability at least $1-qd/N$, while commitments that mix all rows reach $2^{-\lambda}$ with $O(\lambda)$ queries. Our defence checks every matrix product of an exact int8 model with the evaluation protocol of a linear-code polynomial commitment, using only a hash function. It lets a client without weights or GPU check an untrusted provider of an open-weight model, and a CPU
client verifies a 2{,}048-token Llama-2-7B prompt 4.6 times faster than it could re-execute it. A variant shrinks long-prompt proofs 1.7--2.3 times, but proofs still grow with the prompt.
\end{abstract}
